# Internship Recommendation Platform

A full-stack MERN application that recommends internships to students based on their profile, skills, CGPA, and branch.

## Features

- User Registration & Login
- JWT Authentication
- Student Profile Management
- Internship Management
- Internship Recommendation Engine
- Responsive React Frontend

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Tailwind CSS
